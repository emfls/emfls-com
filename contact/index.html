Reader Support & Corrections

Contact Us

Report a technical correction, inaccessible diagram, or broken link in the public EMFLS Studio Journal GitHub issue tracker. Posting requires a GitHub account.

What to Include

Include the article URL, the relevant passage or diagram label, and what you expected to see. For a layout problem, include your browser and approximate screen width.

Private Inquiries

GitHub issues are public. Keep personal information, privacy requests, and other confidential matters out of the tracker. A private contact channel is currently unavailable. See our Privacy Policy for information on how GitHub and Google handle data.
